# The Refrain — permanent creative-access contract

Owner direction, 2026-11-24.

- No advertisements, licensing charges for the applications, subscriptions, paywalls or hidden fees.
- No official account or mandatory login. Personal recordings and projects remain on the musician's local computer; no upload, publication, analytics collection or model training by the apps.
- Local, non-destructive processing; explicit saves and portable backups. Original takes never overwritten.
- Every readable interface label, button, input, tooltip, status, footer, timeline and canvas label must be at least 16 CSS px. Larger titles encouraged. Test browser zoom and tablet layout; do not shrink labels to fit.
- Downloadable, independently runnable local applications are a required delivery target. Hosted browser edition is not proof of offline operation. Audit external scripts, fonts, samples and dependencies; bundle only authorized assets. No mandatory online license checks or cloud account.
- Recording Booth must expose device selection, record/pause/resume/stop, review, explicit save and confirmed delete, input signal indication, and useful error/recovery guidance. USB microphones and audio interfaces are selectable when exposed by the OS/browser. Physical accessory ports, MIDI, hardware routing, latency calibration and native device access require separate implementation and testing.
- Never promise persistence until file saving is confirmed by the user. Unsaved session recordings can be lost on reload or crash.
