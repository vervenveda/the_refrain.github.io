How to compose

Choose a note length, then tap a staff line or space to insert its pitch. Use rests for silence and bar lines to separate phrases. Select an existing event below the staff to insert before it or replace it. Notes play from left to right in the order shown, using the selected tempo.

Treble and bass clefs change the display, not the actual pitches already written. Accidentals apply to the individual note; this beginner editor does not enforce key signatures or automatic measure rules. Playback is monophonic. Close eyes mode hides the score while you listen.
